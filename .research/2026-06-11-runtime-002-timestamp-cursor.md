# Research: RUNTIME-002 Timestamp Cursor

## Summary

Runtime timestamp ownership is centralized in `RuntimeActionFinalizer`. The finalizer stores one cursor, initializes it to `-1`, and advances that cursor both when actions are finalized and when runtime code reserves a timestamp for non-action outputs such as context requests and selected-move resolver requests (`lib/src/runtime/runtime_action_finalizer.dart:7`, `lib/src/runtime/runtime_action_finalizer.dart:14`, `lib/src/runtime/runtime_action_finalizer.dart:23`, `lib/src/runtime/runtime_action_finalizer.dart:35`).

Two RUNTIME-002 paths currently resolve timestamps before the output is known to be publicly delivered or accepted. Direct and pointer context-action requests resolve timestamps inside `InteractionEngine` before `RuntimeRoot` queues the request for asynchronous stream delivery (`lib/src/interaction/interaction_engine.dart:294`, `lib/src/interaction/interaction_engine.dart:1001`, `lib/src/runtime/runtime_root.dart:1818`). Selected move with a configured resolver reserves a timestamp before invoking the resolver, then treats `CanvasMoveCancel` or zero resolved delta as cleanup without an action (`lib/src/runtime/runtime_root.dart:1863`, `lib/src/runtime/runtime_root.dart:1866`, `lib/src/runtime/runtime_root.dart:1880`, `lib/src/runtime/runtime_root.dart:1881`).

Existing tests cover monotonic accepted action timestamps, asynchronous context request delivery, queued request suppression on load/dispose, accepted selected-move resolver request/action timestamp ordering, and resolver cancel without move effects (`test/api/fixtures/runtime_timestamp_order_fixture.dart:12`, `test/runtime/fixtures/load_interaction_cleanup_fixture.dart:229`, `test/interaction/fixtures/move_machine_fixture.dart:911`, `test/interaction/fixtures/move_machine_fixture.dart:951`, `test/interaction/fixtures/move_machine_fixture.dart:961`). Search did not find a test that checks the next accepted timestamp after a suppressed queued context request or after selected-move resolver cancel.
