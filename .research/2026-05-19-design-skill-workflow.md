# Research: Design Skill Workflow

## Summary

The current repository workflow already has a factual research phase and a contract-centered planning phase, but no inspected source-of-truth document names a separate design-decision artifact family. The `research-codebase` skill saves objective notes under `.research/`, while `change-contract` drafts a normative execution plan before implementation and requires lock-required architecture facts to be evidence-backed before using `Contract Mode: FULL` (`.agents/skills/research-codebase/SKILL.md:3`; `.agents/skills/research-codebase/SKILL.md:85`; `.agents/skills/change-contract/SKILL.md:23`; `.agents/skills/change-contract/SKILL.md:31`).
