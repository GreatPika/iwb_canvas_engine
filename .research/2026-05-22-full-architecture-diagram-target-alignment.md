# Research: Full Architecture Diagram Target Alignment

## Summary

`docs/diagrams/generated/full_architecture.mmd` reflects the target architecture at the graph-checkable topology level. The file identifies itself as generated, names `docs/architecture/architecture_graph.yaml` as its source, declares the view as `Full architecture graph`, and records selected phase `P4` (`docs/diagrams/generated/full_architecture.mmd:1`, `docs/diagrams/generated/full_architecture.mmd:2`, `docs/diagrams/generated/full_architecture.mmd:3`, `docs/diagrams/generated/full_architecture.mmd:4`).
