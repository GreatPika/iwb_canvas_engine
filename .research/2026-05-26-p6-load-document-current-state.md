# Research: P6 Load Document Current State

## Summary

P6 is currently documented as the phase that will turn full document replacement into a staged operation: validate public input, materialize `PreparedDocumentLoad`, interrupt interaction only after preparation succeeds, atomically replace the committed document and clear selection, initialize runtime view camera, invalidate caches, and publish one `CanvasRuntimeState` (`docs/implementation/p6_load_document.md:8`, `docs/implementation/p6_load_document.md:14`, `docs/contracts/load_document.md:61`, `docs/contracts/load_document.md:78`). The codebase already exposes the public API entries for `CanvasEditPort.loadDocument` and `CanvasEdit.replaceDraftDocument`, but both are current P6 placeholders that throw `UnsupportedError` before replacement behavior runs (`lib/src/api/canvas_runtime.dart:176`, `lib/src/api/canvas_runtime.dart:202`, `lib/src/edit/edit_kernel.dart:79`, `lib/src/edit/edit_session.dart:126`).

The current implemented path is the P5 edit path. `CanvasRuntime.edits` delegates to `RuntimeRoot.edits`, which is backed by `EditKernel`; `EditKernel.edit` creates a `DraftDocument`, compiles a `CommitPlan`, installs document and selection effects through `CommitApplier`, then `RuntimeRoot` publishes state and delivers typed effects (`lib/src/api/canvas_runtime.dart:41`, `lib/src/runtime/runtime_root.dart:71`, `lib/src/edit/edit_kernel.dart:47`, `lib/src/edit/edit_kernel.dart:61`, `lib/src/runtime/runtime_root.dart:337`, `lib/src/runtime/runtime_root.dart:346`). The data/model side already has DTO freezing, metadata validation, validated import draft checks, committed-store materialization, projection caching, and selection-owner separation that P6 can observe as existing behavior (`lib/src/api/canvas_document.dart:23`, `lib/src/api/canvas_metadata.dart:12`, `lib/src/codec/validated_import_draft.dart:9`, `lib/src/store/document_store_kernel.dart:24`, `lib/src/selection/selection_kernel.dart:7`).

Verification currently proves placeholder rejection, edit rollback, state publication for normal edits, runtime/persisted camera separation, selection/runtime owner separation, DTO immutability, and projection-only public document reads (`test/edit/fixtures/sync_non_nested_async_stale_fixture.dart:225`, `test/edit/fixtures/rollback_fixture.dart:29`, `test/runtime/runtime_state_publication_test.dart:117`, `test/runtime/runtime_camera_port_test.dart:25`, `test/selection/fixtures/runtime_owner_separation_fixture.dart:50`, `test/api_contract/dto_immutability_test.dart:45`, `test/store/fixtures/read_document_projection_fixture.dart:7`). The P6-named staged load tests are referenced by docs but are not present in the current test tree (`docs/implementation/p6_load_document.md:77`, `docs/implementation/p6_load_document.md:78`).
