# Plan

so current roadmap work can be updated without mixing execution contracts.

Step entry template: `- [ ] [Step <number>. <Short step title>](plan/step_<number>_<short_snake_case_summary>.md)`

## General Notes

- Step order defines the intended implementation order for currently retained
  work.
- Detailed scope, closure rules, and verification live only in the linked step
  document.
- Completed step contracts that no longer own current work are removed from
  this index and from `plan/` instead of remaining as stale navigation.
- When a step is completed, update both this index and the linked step
  document in the same change.
