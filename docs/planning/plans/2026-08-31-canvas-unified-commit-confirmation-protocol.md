# Change Contract

## Goal

Every admitted Draw, Delete, Erase, Move, Rotate, Reflect, and TextEdit operation can be approved synchronously before committed mutation through one required public resolver, with immutable facts sufficient for host-owned Undo/Redo, one irreversible document/selection/ID installation, and exactly one attempted lease terminal determined by actual application. Existing sparse ownership, operation eligibility, service-edit exemptions, action payloads, and serialized document compatibility remain intact; public restoration edits can restore selection and remove a Draw-created empty layer atomically.

## Boundaries

Owner: Runtime owns semantic classification, synchronous resolution, lease finality, cleanup sequencing, and public delivery. Edit owns preparation and the single-use apply capability; Store owns committed document/revisions/ID ledgers; Selection owns selected IDs/revision; Interaction owns gesture capture and cleanup; Frame consumes immutable capture inputs. Declaration-only contracts carry values/ports below implementation owners. The host alone owns retained history and assets.
