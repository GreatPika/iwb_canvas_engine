# Change Contract

## Goal

Committed element families, layer rows, resource-reference summaries, and generated-id admission directly maintain and expose the exact facts needed by the later store transaction candidate. The current sparse family path uses one consume-once editor with lazy copy-on-write ownership per family map, exclusive current-state decisions, family-owned normalization, and one accepted freeze, without retained membership mirrors, displaced document-sized work, or any change to current public, import, edit, projection, diagnostic, ordering, or runtime-route behavior.
