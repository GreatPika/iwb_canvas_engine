# Research: Double-Tap Docs Current Contract

## Summary

The current root-package documentation describes double-tap as a text-edit request path only. The primary contract says a double-tap on a visible selectable text element emits `CanvasTextEditRequested`, does not mutate the document, and does not select or deselect by itself (`docs/contracts/interaction_engine.md:215`, `docs/contracts/interaction_engine.md:217`, `docs/contracts/interaction_engine.md:218`, `docs/contracts/interaction_engine.md:219`). The public API repeats that the engine detects double-tap on text and emits `CanvasTextEditRequested`; the application owns the Flutter editor overlay and later calls `CanvasCommandPort.commitTextEdit(requestId, newText)` (`docs/contracts/public_api_v1.md:2239`, `docs/contracts/public_api_v1.md:2242`, `docs/contracts/public_api_v1.md:2246`, `docs/contracts/public_api_v1.md:2251`, `docs/contracts/public_api_v1.md:2252`).

The current text-only behavior is constrained by hit-test eligibility, candidate matching, cleanup, stale-guard, and effect-matrix rules. Point hit testing is content-layer only, requires finite point, visibility, selectability, and finite transform, and excludes background elements from pointer selectability in v1 (`docs/contracts/geometry.md:54`, `docs/contracts/geometry.md:57`, `docs/contracts/geometry.md:63`, `docs/contracts/geometry.md:67`). The text request state machine explicitly turns no-hit and non-text top-hit paths into no request or cleanup-only paths (`docs/diagrams/state_pending_text_edit_request.mmd:33`, `docs/diagrams/state_pending_text_edit_request.mmd:34`, `docs/diagrams/state_pending_text_edit_request.mmd:67`, `docs/diagrams/state_pending_text_edit_request.mmd:68`).

The current docs also mark broader contextual action as out of scope for this phase. `CanvasInteractionRequestId` is described as compatible with a future contextual-action request API, while the current phase does not introduce a full contextual-action event for shapes, images, lines, or empty canvas (`docs/contracts/interaction_engine.md:246`, `docs/contracts/interaction_engine.md:247`, `docs/contracts/interaction_engine.md:248`).
