# Research: Deletion, Eraser, and Selection Policies

## Summary

Selection deletion and terminal eraser deletion both build sparse document edits through `EditKernel.prepareInteractionCommit`, but they enter the runtime through separate paths. `RuntimeRoot.deleteSelection` derives an ordered list of deletable selected IDs and removes them in one prepared interaction commit. Pointer handling delivers an `EraserCommitIntent` to `_deliverEraserCommit`, which prepares removals for its erased IDs and then performs eraser cleanup. A public document snapshot contains each complete element and, for content elements, the containing layer and their ordered layer list; the internal store also exposes these reads separately. In both deletion paths, the store separates sparse commit preparation from installation, and public action events are finalized only by the post-install delivery path. `lib/src/runtime/runtime_root.dart:863`; `lib/src/runtime/runtime_root.dart:2397`; `lib/src/api/canvas_runtime.dart:36`; `lib/src/contracts/public/canvas_document.dart:64`; `lib/src/store/document_store_kernel.dart:88`; `lib/src/edit/edit_kernel.dart:113`; `lib/src/store/document_store_kernel.dart:380`; `lib/src/store/document_store_kernel.dart:495`.

The eraser reads candidates from the paint spatial index, resolves frame facts, applies the candidate limit, then counts and exact-checks every resolved candidate. The current exact-hit function has a switch covering every fixed `CanvasElementKind`; no inspected public runtime configuration accepts eraser element kinds. `lib/src/runtime/runtime_interaction_read_adapter.dart:325`; `lib/src/geometry/hit_test_policy.dart:162`; `lib/src/contracts/public/canvas_element.dart:11`; `lib/src/contracts/public/canvas_runtime.dart:22`.

The public selection surface exposes selected IDs, selected count, and a delete command. The internal fact object used by that command contains only ordered `deletableIds`; it excludes background and `isDeletable: false` elements. The existing command removes this subset, which is covered by a test retaining a non-deletable selected element after deleting a deletable selected element. `lib/src/contracts/public/canvas_runtime.dart:105`; `lib/src/contracts/internal/command_facts_port.dart:27`; `lib/src/runtime/runtime_command_facts_adapter.dart:60`; `lib/src/runtime/runtime_root.dart:863`; `test/api/fixtures/selection_transform_commands_fixture.dart:136`.
