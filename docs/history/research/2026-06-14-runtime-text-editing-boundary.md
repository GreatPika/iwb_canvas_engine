# Research: Runtime Text Editing Boundary

## Summary

The current repository already describes inline text editing as a runtime-owned boundary, not as surface, interaction, frame, or public API ownership. `CanvasTextEditingPort` owns one active runtime text edit session, read-only admission, live geometry/style projection, and guarded commit/dismiss lifecycle, while it must not own Flutter `EditableText`, app decoration, context menus, or document visibility hiding (`docs/architecture/01_runtime_ownership.md:62`, `docs/architecture/01_runtime_ownership.md:196`). The implementation currently keeps that boundary as private classes inside `lib/src/runtime/runtime_root.dart`, with `_RuntimeTextEditingPort` implementing the public port and holding active session state, candidate state, read-only state, and a suppression token (`lib/src/runtime/runtime_root.dart:3024`, `lib/src/runtime/runtime_root.dart:3028`, `lib/src/runtime/runtime_root.dart:3031`).

An extraction can be architecture-clean only if it stays under runtime ownership, keeps public exports unchanged, avoids `part`/`part of`, and receives narrow host capabilities instead of `RuntimeRoot`. The code facts show the boundary needs mutation admission, interaction request guard reads/consumption, frame facts and measured text layout projection, text commit preparation/delivery, runtime interaction-state publication, and load/dispose cleanup hooks (`lib/src/runtime/runtime_root.dart:1024`, `lib/src/runtime/runtime_root.dart:1027`, `lib/src/runtime/runtime_root.dart:1074`, `lib/src/runtime/runtime_root.dart:1728`, `lib/src/runtime/runtime_root.dart:1771`, `lib/src/runtime/runtime_root.dart:1897`, `lib/src/runtime/runtime_root.dart:3227`, `lib/src/runtime/runtime_root.dart:3239`, `lib/src/runtime/runtime_root.dart:3309`, `lib/src/runtime/runtime_root.dart:3427`).

The main extraction risk is not only Dart access control. Several tests and guardrails depend on the current source shape: `interaction.text_edit_stale_commit_guard` reads only `lib/src/runtime/runtime_root.dart` and AST-checks `commitTextEdit`; `test/runtime/fixtures/text_editing_port_fixture.dart` string-checks that runtime text editing uses measured layout and does not use `TextPainter` or `text.length`; text/surface guardrails scan runtime files for formula text bounds and non-surface `EditableText` use (`tool/guardrails/src/interaction_guardrail_checks.dart:170`, `tool/guardrails/src/interaction_guardrail_checks.dart:189`, `test/runtime/fixtures/text_editing_port_fixture.dart:124`, `tool/guardrails/src/text_surface_guardrail_checks.dart:43`, `tool/guardrails/src/text_surface_guardrail_checks.dart:171`).

## Extraction Options Observed From Current Facts

### Option A: Extract Session Port Only

- **Shape**: move `_TextEditActiveSessionNotifier`, `_RuntimeTextEditingPort`, `_RuntimeTextEditSessionState`, and `_TextEditSuppressionToken` to a new private runtime-owned file such as `lib/src/runtime/runtime_text_editing_controller.dart`, keep `RuntimeRoot.commitTextEdit` and commit helpers in `runtime_root.dart`.
- **Fits current facts because**: docs already identify `CanvasTextEditingPort` as a runtime-owned active session boundary (`docs/architecture/01_runtime_ownership.md:196`), and production source boundary rules allow implementation owners under `lib/src/runtime/**` while forbidding `part`/`part of` only for production `lib/**` (`docs/architecture/02_package_boundaries.md:227`, `docs/architecture/02_package_boundaries.md:229`).
- **Costs visible in current code**: the extracted controller would need host callbacks for mutation admission, guard facts, frame facts, geometry projection, commit, and publication because the current private class calls root methods and fields directly (`lib/src/runtime/runtime_root.dart:3031`, `lib/src/runtime/runtime_root.dart:3107`, `lib/src/runtime/runtime_root.dart:3227`, `lib/src/runtime/runtime_root.dart:3239`, `lib/src/runtime/runtime_root.dart:3309`, `lib/src/runtime/runtime_root.dart:3407`, `lib/src/runtime/runtime_root.dart:3428`, `lib/src/runtime/runtime_root.dart:3435`, `lib/src/runtime/runtime_root.dart:3440`).

### Option B: Extract Session Port Plus Text Commit Coordinator

- **Shape**: move the active session port and `commitTextEdit` command logic into a runtime-owned controller/coordinator; `RuntimeRoot` keeps the public facade adapter and delegates command calls to the controller.
- **Fits current facts because**: `CanvasTextEditingPort` is the active session owner and commits through the guarded command path, not through surface or interaction ownership (`docs/architecture/01_runtime_ownership.md:196`, `docs/contracts/public_api_v1.md:2466`, `docs/contracts/public_api_v1.md:2470`).
- **Costs visible in current code**: this option requires a larger narrow host: edit prepare/delivery, interaction guard decision/consumption, validation, anchor projection, active-session cleanup, and publication must cross the controller boundary (`lib/src/runtime/runtime_root.dart:1025`, `lib/src/runtime/runtime_root.dart:1027`, `lib/src/runtime/runtime_root.dart:1051`, `lib/src/runtime/runtime_root.dart:1059`, `lib/src/runtime/runtime_root.dart:1074`, `lib/src/runtime/runtime_root.dart:1728`). It also requires rewriting `interaction.text_edit_stale_commit_guard`, which currently reads only `runtime_root.dart` and method `commitTextEdit` (`tool/guardrails/src/interaction_guardrail_checks.dart:170`, `tool/guardrails/src/interaction_guardrail_checks.dart:202`).

### Option C: Extract Pure Text Geometry/Anchor Projection Only

- **Shape**: move `_validateTextEditCommandInput`, `_textEditAnchorLocalFor`, `_resolvedHorizontalTextAnchor`, `_TextEditHorizontalAnchor`, and live frame-fact/geometry projection into a runtime-owned helper while leaving session and commit ownership in `runtime_root.dart`.
- **Fits current facts because**: text geometry already uses measured layout rather than formula bounds (`lib/src/geometry/geometry_policy.dart:386`, `lib/src/geometry/geometry_policy.dart:409`, `docs/contracts/frame_rendering.md:145`).
- **Costs visible in current code**: this does not extract the active session boundary described in architecture; it mostly reduces local helper size. It would still need source-shape checks to avoid triggering the runtime formula-bound guardrail, which scans `lib/src/runtime/**` (`tool/guardrails/src/text_surface_guardrail_checks.dart:171`).

## Minimal Host/Controller Interface If Extracted

The smallest interface that avoids passing `RuntimeRoot` is a runtime-private host consumed by a runtime-private controller. The names below are descriptive; they are not current code.

- `ensureTextEditingOperationAllowed()`: delegates current `ensureRuntimeMutationAllowed()` so every public port/session callback keeps disposed/edit/load/resolver guard behavior (`lib/src/runtime/runtime_root.dart:1024`, `lib/src/runtime/runtime_root.dart:3061`, `lib/src/runtime/runtime_root.dart:3264`, `lib/src/runtime/runtime_root.dart:3394`).
- `requestFactsFor(CanvasInteractionRequestId)`: returns live `InteractionRequestGuardFacts?` for candidate and stale checks, replacing direct `_interactionEngine.requestFactsFor` calls (`lib/src/runtime/runtime_root.dart:3227`, `lib/src/runtime/runtime_root.dart:3359`).
- `currentTextGuardFacts(InteractionRequestGuardFacts)`: returns `TextCommitGuardReadFacts`, replacing `_interactionReadPort.textCommitGuardFacts` inside `_currentGuardFacts` (`lib/src/runtime/runtime_root.dart:3297`, `lib/src/runtime/runtime_root.dart:3309`).
- `frameFactsForElement(CanvasElementId)`: returns `FrameElementFacts?` for candidate base facts and commit anchor inputs (`lib/src/runtime/runtime_root.dart:644`, `lib/src/runtime/runtime_root.dart:1140`, `lib/src/runtime/runtime_root.dart:3239`).
- `textGeometryFor(FrameElementFacts, String liveText)` or a narrower `RuntimeTextGeometryProjector`: performs measured layout, anchor-preserving transform, live frame-fact copy, and `GeometryPolicy` bounds; this bundles the current `_measuredTextLayoutFromFrameFacts`, `_textEditAnchorPreservingTransformForLayout`, `_textFrameFactsWithLiveText`, and `GeometryPolicy().boundsFor` sequence without exposing the full root (`lib/src/runtime/runtime_root.dart:736`, `lib/src/runtime/runtime_root.dart:1119`, `lib/src/runtime/runtime_root.dart:653`, `lib/src/runtime/runtime_root.dart:3427`, `lib/src/runtime/runtime_root.dart:3446`).
- `commitTextEdit(requestId, liveText, timestampMs)`: if Option A is chosen, the session controller can keep delegating commit to the root command method as it does today (`lib/src/runtime/runtime_root.dart:3407`). If Option B is chosen, this method should be replaced by narrower command-host methods below.
- `publishTextEditInteractionChanged()`: publishes interaction revision and both-layer repaint for start/dismiss/read-only clear (`lib/src/runtime/runtime_root.dart:3107`, `lib/src/runtime/runtime_root.dart:3150`, `lib/src/runtime/runtime_root.dart:3176`, `lib/src/runtime/runtime_root.dart:1728`, `lib/src/runtime/runtime_root.dart:1732`).
- `clearForLoad(publishState: false, notifyActiveSession: false)` and `notifyActiveSessionChanged()`: root load currently clears text editing before interaction request cleanup and notifies after state publication (`lib/src/runtime/runtime_root.dart:1771`, `lib/src/runtime/runtime_root.dart:1897`).

- If the implementation still passes a `RuntimeRoot` reference into the extracted text controller, the extraction would preserve the current broad dependency in another file rather than creating a narrow boundary (`lib/src/runtime/runtime_root.dart:3029`, `lib/src/runtime/runtime_root.dart:3031`).
