# Diagnostics Performance And Debug Surfaces

## Purpose

This family owns diagnostics, benchmark tooling, debug surfaces, and
performance proof contours.

## Target Rules

- Diagnostic and benchmark outputs use truthful schemas and stable units.
- Performance proof is generated by repository tools, not hand-written claims.

## Forbidden Shapes

- Do not emit benchmark reports that bypass runner-side validation.
- Do not compare malformed load-profile diff inputs after report identity has
  become lossy.
- Do not emit benchmark metric values through unit-specific field names unless
  the field unit is true for every metric using that field.
