# Change Contract

## Goal

Implement P9 as the engine's internal frame rendering and cache layer: `FrameEngine` captures immutable main and overlay frame inputs, builds bounded painter-safe paint plans and render records through the documented seven frame-private collaborators, keeps ordinary paint-record caches independent from selection, preview, background, grid, camera, and resolver churn, exposes readable public preview state without P10 preview producers, and closes P9 graph, guardrail, documentation, and public smoke evidence.

## Boundaries

Owner:

`lib/src/frame/**` owns `FrameEngine`, captured frame models, render records, paint plans, passive painter inputs, repaint buses, and bounded frame-owned derived caches. `FrameCaptureService`, `OrdinaryPaintPlanner`, `SelectedMoveSupplementPlanner`, `SelectionDecorationPlanner`, `PaintAssetBindingService`, `StaticBackgroundPlanner`, and `OverlayPreviewPlanner` are the frame-private collaborators. `RuntimeRoot` owns exposing the public preview read value and composing frame dependencies. `lib/src/api/canvas_runtime_frame_bridge.dart` owns the internal-only bridge from a public `CanvasRuntime` instance to its `RuntimeRoot` for `CanvasSurface` passive frame capture; it is not exported from the root barrel and does not add a public `CanvasRuntime` getter. `FrameFactsPort`, `SelectionFactsPort`, `SpatialKernel`, and `SurfaceResourceSession` remain the source seams for committed facts, selection facts, spatial candidates, and image resolution/cache policy respectively.

In Scope:

Create the P9 frame-private implementation under `lib/src/frame/**`; add immutable captured main/overlay frame and painter output models; implement ordinary paint planning, render records, selected supplement staging, selection decoration planning, static background planning, overlay preview admission, asset binding, repaint bus output, and bounded frame-owned cache policies; close `CanvasRuntime.preview` as a readable immutable public value defaulting to `CanvasNoPreview`; add `lib/src/api/canvas_runtime_frame_bridge.dart` as an internal bridge that registers and unregisters the `RuntimeRoot` for each `CanvasRuntime` instance; add P9-only passive painter adapters under `lib/src/frame/main_frame_painter.dart` and `lib/src/frame/overlay_frame_painter.dart`; update `lib/src/api/canvas_surface.dart` only enough to look up the runtime root through that internal bridge and host immutable frame output in a `CustomPaint` keyed with `const ValueKey<String>('iwb_canvas_surface.paint_host')`; extend focused frame tests, public API/smoke tests, guardrails, architecture graph, diagrams, verification docs, generated docs indexes, and P9 phase evidence.

Out of Scope:

Do not expose frame collaborators through `lib/iwb_canvas_engine.dart` or other public barrels. Do not add public hit-test, paint-query, preview-mutation, selected-move, resource-session, painter, cache, `RuntimeRoot`, or frame-bridge APIs. Do not implement P10 interaction-owned preview producers, pointer sessions, selected-move commit/cancel behavior, or preview mutation state machines. Do not implement P13 single-active-surface gating, pointer adapters, surface attach/detach lifecycle, resolver session ownership lifecycle, runtime-swap lifecycle, interaction routing, or full `lib/src/surface/**` surface painters. Do not make `CanvasSurface` own active resource-session attachment, runtime-swap cleanup, asset binding, resolver calls, or pointer input in P9; its P9 change is limited to resource-free passive `CustomPaint` hosting of immutable frame output behind the existing public widget. Do not replace `FrameFactsPort`, `SelectionFactsPort`, `SpatialKernel`, or `SurfaceResourceSession` with new duplicate source seams. Do not materialize `CanvasDocument` for paint input, import concrete store kernels into frame code, use `ResourceCatalogPort` as the frame asset seam, or create `FrameRenderer` solely to satisfy stale graph text.

Source of Truth:

P9 scope and collaborator ownership come from `.design/2026-05-29-p9-frame-rendering-and-caches.md` and `docs/implementation/p9_frame_rendering_and_caches.md`. Frame capture, render records, selected supplement staging, and painter rules come from `docs/contracts/frame_rendering.md`. Cache ownership and invalidation rules come from `docs/contracts/cache_policy.md`. Resource image resolution rules come from `docs/contracts/resources.md`. Spatial candidate constraints come from `docs/contracts/spatial_kernel.md`. Package/import boundaries come from `docs/architecture/02_package_boundaries.md` and `docs/architecture/architecture_graph.yaml`. Test and guardrail inventory come from `docs/verification/tests.md`, `docs/verification/guardrails.md`, and `tool/guardrails/src/guardrail_registry.dart`.

Compatibility:

The public package API remains source-compatible. `CanvasRuntime.preview` changes from throwing to returning a readable immutable `CanvasPreviewState`, defaulting to `CanvasNoPreview`; no new public mutation surface is introduced. Existing runtime state revisions remain compatible, including `previewRevision`. Frame implementation files remain internal and are not exported. Public smoke may construct or pump public surface/frame paths only through the public package import and must assert public behavior rather than internal cache details.

Order Constraints:

First create frame models and capture boundaries over existing seams. Then implement ordinary committed paint planning and bounded ordinary caches before any selected, preview, background, or asset binding behavior depends on them. Then add separate selected supplement, selection decoration, static background, and overlay preview planners without ordinary cache writes. Then bind assets through `PaintAssetBindingService` after planning, calling `SurfaceResourceSession.beginFrameResourcePass` before per-frame resolution. Then add the internal `CanvasRuntime` to `RuntimeRoot` bridge and expose passive painter/repaint outputs plus the public preview read path through `CanvasSurface`'s `CustomPaint` host keyed `iwb_canvas_surface.paint_host`. Add guardrails and graph/docs closure only after concrete production surfaces and file names exist. Extend public smoke after the public preview and passive `CanvasSurface` frame path exist. Mark Step 43 complete only after all units and verification gates pass.

Temporal and all-or-nothing constraints:

Frame capture must snapshot `FrameFactsPort`, selection facts, preview value plus preview revision, viewport/DPR/style inputs, and spatial paint candidates once per main or overlay frame request before planning. Painters may observe only immutable frame output and must not call back into runtime, store, resolver, or public document projection during paint. The ordinary `OrdinaryPaintRecordCache` write is the irreversible frame-cache point: key construction, committed row resolution, spatial candidate admission, and ordinary record construction must complete before writing the cache entry; selected supplement records, selection decoration, overlay preview records, static background records, and asset bindings are later derived outputs and must not mutate that ordinary entry. Resolver/session calls are allowed only after ordinary plan construction and are failure-contained as session-owned image, placeholder, null-suppression, or budget outcomes.
