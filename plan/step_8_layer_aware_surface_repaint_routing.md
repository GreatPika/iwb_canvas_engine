# Change Contract

## Goal

Implement the layer-aware repaint routing selected by the architecture design so
runtime-owned repaint targets guide the real Flutter surface before frame output
construction. Overlay-only previews must update only the overlay output and
overlay paint layer; main-only selected-move, selection, and resource-dirty
changes must update only the main output and main paint layer; camera, bootstrap,
runtime swap, and unknown signals must update both layers while preserving the
public `CanvasSurface` API and immutable-output painter boundary.

## Boundaries

Owner: `RuntimeRoot` owns internal repaint target aggregation and surface-frame publication. `CanvasRuntimeSurfacePort` owns the active-surface bridge signal. `_CanvasSurfaceState` and `SurfaceFrameOutputCache` own transient Flutter adapter output caching, local input invalidation, listener lifecycle, and layer output notifiers. `FrameEngine` and existing frame collaborators own output construction and `FrameRepaintSignal`. `MainFramePainter` and `OverlayFramePainter` own painting immutable layer outputs only. Source-of-truth docs and diagrams own durable architecture meaning after the behavior changes.

In Scope:

- Add non-public `CanvasRuntimeSurfaceFrame` and `CanvasSurfaceRepaintTarget` values to `lib/src/api/canvas_runtime_surface_bridge.dart` with current `CanvasRuntimeState`, a monotonically increasing generation, and `mainCanvas`/`overlayCanvas`/`reason` target fields.
- Publish surface frames from `RuntimeRoot` from existing repaint/effect and publication owners so runtime-owned repaint intent reaches the surface before frame output construction.
- Map interaction preview, cleanup, selection, resource dirty, load, camera, and unknown/unclassified runtime paths to layer targets using existing operation/interaction/effect source-of-truth rules.
- Add `SurfaceFrameOutputCache` in `lib/src/surface/surface_frame_output_cache.dart` to hold only transient main/overlay immutable outputs, local input keys, and layer output notifiers.
- Replace `CanvasSurface` state-driven both-output construction with cache-driven targeted output builds while preserving bounded layout, layout-size / viewport derivation, pointer routing, resource session, active surface, runtime swap, interactive, and public constructor behavior.
- Split the current single `CustomPaint`/foreground-painter host into independently repaintable main and overlay paint layers using layer output listenables.
- Preserve painter no-live-runtime-read behavior: painters consume immutable `MainFramePaintOutput` and `OverlayFramePaintOutput` values and do not receive runtime/store/document/resolver/session access.
- Add direct build-counter, notifier/paint, resource, camera, lifecycle, failure-injection, and import/semantic proof surfaces for the changed routing behavior.
- Update or explicitly verify durable source-of-truth docs, diagrams, graph evidence, verification docs, guardrails, and generated indexes affected by the new runtime/surface invalidation seam.

Out of Scope:

- Changing public `CanvasSurface` constructor parameters, public runtime DTOs, public preview DTOs, resource resolver API, or public API registries for DTO shape.
- Moving frame planning, `FrameRepaintSignal`, ordinary paint cache ownership, overlay preview planning, or resource resolver ownership into `CanvasSurface`.
- Importing `frame_repaint_signal.dart` into `canvas_runtime_surface_bridge.dart` or using frame output repaint signals as the pre-output surface invalidation source.
- Making painters build or fetch outputs during `paint`, or letting painters read runtime, store, document, resolver, resource session, or public projection state.
- Adding broad synchronizers, background jobs, duplicate durable repaint sources of truth, public benchmark hooks, production counters, or fixture-only production state.
- Requiring visual screenshots, timing-only benchmarks, or frame-level repaint signal tests as the sole proof for skipped surface output construction or skipped layer repaint.
- Retiring existing frame repaint signal tests or benchmark cases; they remain lower-level and performance-contour proof.

Source of Truth: Runtime/interaction/operation/effect source-of-truth rules own repaint target meaning. `CanvasSurfaceRepaintTarget` is one transient internal delivery of that meaning to the active surface before output construction; `FrameRepaintSignal` remains frame-owned output metadata. `SurfaceFrameOutputCache` is explicit performance duplication of derived immutable frame outputs only, with the invariant that a cached layer output is valid until its runtime layer signal or surface-local input key invalidates it. Source-of-truth documentation must describe this split instead of duplicating preview/operation target tables in the surface.

Compatibility: Public API shape, public DTOs, resource resolver contract, pointer behavior, bounded-layout failure behavior, single-active-surface behavior, runtime state publication semantics, and visual output are preserved. Unknown or unclassified runtime changes conservatively rebuild both layers. For fallible output builds, prior published outputs remain visible until the targeted replacement build succeeds; exceptions continue to surface consistently with current frame build behavior. Existing tests that assert frame-level `FrameRepaintSignal` values remain valid.

Order Constraints:

1. Add internal bridge signal types and runtime target aggregation before `CanvasSurface` consumes the signal.
2. Preserve active attach sequencing: accepted active-surface attach succeeds, session installs, initial local inputs are known, bootstrap builds both outputs, then the surface-frame listener starts. Rejected second attach installs no listener, session, cache output, pointer, paint, or resolver side effects.
3. Introduce `SurfaceFrameOutputCache` before replacing painter delegates or splitting the paint host so output construction has a stable owner and proof seam.
4. For a layer signal, build the targeted output into a local value before assigning that layer notifier. For a both-layer signal, build both outputs into locals before publishing either notifier. Notifier assignment is the irreversible point.
5. Schedule resource budget follow-up only after a main output build and keep mounted/runtime/port/session identity guards beside the surface lifecycle owner.
6. Split main and overlay paint hosts before claiming independent layer repaint behavior.
7. Update source-of-truth docs, diagrams, graph evidence, and generated docs in the same implementation step when their durable meaning changes.
