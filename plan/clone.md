## 1) Удалить грубую нормализацию и сделать один информативный канонизатор

**Это обязательно. Новый режим не нужен. Грубую нормализацию удалить.**

Что реализовать:

- убрать логику вида `IDENTIFIER -> ID`
- убрать грубую замену литералов без контекста
- не добавлять второй режим
- сделать **один** канонизатор по дереву разбора:
  - параметры → `PARAM_n`
  - локальные переменные → `LOCAL_n`
  - сохранять:
    - имена типов
    - имена полей
    - имена вызываемых методов
    - имена конструкторов
    - аннотации
    - исключения

  - литералы нормализовать умеренно:
    - `INT`, `DOUBLE`, `STR`, `true`, `false`, `null`

Что это даст:

- меньше шума
- больше архитектурного смысла
- меньше лишнего кода, чем при поддержке нескольких режимов

**Править:**

- `analysis/src/clone_analysis_collector.dart`
- `analysis/src/clone_analysis_models.dart`
- `analysis/src/clone_analysis_report.dart`

**Создать:**

- `analysis/src/clone_analysis_canonicalizer.dart`
